# FIFA-World-Cup-2026-Prediction-Tournament-Winner-Classification

Python · scikit-learn · Pandas · Matplotlib · Seaborn · Random Forest · Logistic Regression · Google Colab

- Built a binary classification system on historical FIFA World Cup data (1930–2022) to predict the probability of each nation winning the 2026 tournament.

- Engineered custom features including recency-weighted performance scores, host-country advantage, and cumulative top-4 finish counts; reshaped a 22-row dataset into 500+ training samples to enable meaningful model training.

- Implemented and compared Logistic Regression and Random Forest classifiers, evaluating performance with confusion matrices and classification reports.

- Applied data cleaning techniques including defunct nation remapping to standardize 90+ years of historical records.
